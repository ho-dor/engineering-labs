# Local dev (not on GitHub)

Matt Pocock Cursor skills are **optional on your machine only**. They are listed in `.gitignore` so they never get pushed.

From the repo root:

```bash
npx skills@latest add mattpocock/skills -a cursor
```

That creates `.agents/skills/`. Run `/setup-matt-pocock-skills` once if you use that workflow locally.

Product/capstone repos may use the same pattern; this labs repo stays focused on small exercises and `.cursor/skills/`.
